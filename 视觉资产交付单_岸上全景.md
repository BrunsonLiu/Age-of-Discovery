# 岸上全景交付单（19 张 + 2 个共用）

> 给画师：这一批只要**一张图/港**，画好按下面的文件名放进 `public/assets/ports/`，
> 剩下的接线（缩略图、面板小图、岸上整屏）我来做。


## 一、硬规格（六条，缺一条就不能用）

| 项 | 要求 |
|---|---|
| 尺寸 | **≥1792×1024**，必须是原生，**不要让工具把小图再放大** |
| 比例 | 16:9（1440 屏 1:1 铺满，2K 屏放大 1.4×） |
| 格式 | WebP，q72；单张 **≤600KB**（岸上整屏是首屏资源） |
| 主体位置 | 港口主体必须落在**画面竖向中间 50%**；上 20% 留天空、下 15% 留水面/空码头 |
| 底部 | 下 15% **不要压暗、不要放主体**（游戏会在那里叠一块石砌码头） |
| 前景 | **不要有人在画面前景做特写**（UI 会压在那里） |

## 二、通用负面提示（每条都带）

```
No text, no watermark, no signature, no frame, no border, no modern elements,
no photographic realism, no 3D render, no lens flare, no HDR glow, no fisheye distortion.
```

## 三、清单

优先级 A 是"开局第一眼 + 跑一趟必经过"的 5 张；B/C 按顺路补。
