test: 全量 e2e 跑通（55 套件 / 1348 断言 / 0 失败）；修三个"工具自己"造成的假象

上一轮只跑了默认组 25 个套件，这轮把剩下的跑完，并顺手修掉工具本身的三处问题。

① 全量结果
   `npm run test:e2e:sweep`：**55 个套件 / 1348 条断言 / 0 失败**，23.7 分钟。
   加上默认组的 25 个，仓库里所有断言型 e2e 都跑过一遍了。

② 跑器（run-suite.mjs）自己的假绿
   各套件汇总文案前缀不统一（「结果：」「结论：」「朝贡闭环 e2e：」…），
   我原来只认「结果：」，于是十几个套件退化成"只信退出码"——而一个套件里
   三十条断言只压成一个 0/1，等于白测。
   改成：**取输出里最后一处「N 通过 / M 失败」**，没有才数行首 ✓/✗。
   顺带更正一条我上轮写错的注释：这些套件**都**有非零退出路径
   （`process.exit(fail === 0 ? 0 : 1)`），我此前只 grep 字面量 `process.exit(1)`
   就断言"从不非零退出"——是错的，已在注释里改正。

③ 两个 online 套件被跑器喂了非法 URL
   `online-check` / `online-load-time` 取 `process.argv[2]` 当 URL，跑器塞的是
   `--port=5174` → `Protocol error: Cannot navigate to invalid URL`，
   在汇总里显示成产品失败。改成"第一个非 -- 开头的参数"。

④ `online-load-time.mjs` 一直在报假数（重写）
   它等「绘制航海图...」这句文案消失——那句早就不存在了，于是"消失"瞬间成立，
   它报 **1.6s**，而同一份输出里 `leaflet:false / landPaths:0`（地图根本没挂上）。
   **给出误导数字的工具比没有更糟。** 重写成与本地探针同一套判据
   （FCP / 开场卡 / `.leaflet-overlay-pane path > 100`），并主动点掉开场卡，
   最后只报一件事：地图挂没挂上；没挂就 exitCode=1。
   现在线上实测：FCP 1.70s、开场卡 2.17s、地图可看 3.71s、传输 2027KB、
   陆地 3418 条 / 港口 78 个。（比本地限速测的慢，是国内到 GitHub Pages 的 RTT 高。）

⑤ 我差点悄悄缩小测试面
   看到 `test:e2e:all` 不存在就直接加了它——其实它存在，且是含 relics / seg6 /
   两个 clickable 视口变体的完整组合，我的跑器**不是它的超集**。
   `npm test` 立刻红（「all 也含遗物巡检」）→ 恢复原 `all`，我的改叫 `test:e2e:sweep`。
   加 npm script 前先看有没有同名键。

验证：单测 11498/0、eslint 干净、全量 e2e 55 套件 1348 断言 0 失败。
